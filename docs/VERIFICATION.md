# Final checklist: what was verified, and how

**Status key:**

- ✅ Implemented, and verified by an automated test and/or screenshots in this repository.
- ⚠️ Implemented with a documented limitation (see [KNOWN_ISSUES.md](../KNOWN_ISSUES.md)).

**Test key:**

- **U** = unit tests (`npm test`).
- **E2E-G / E2E-F / E2E-S / E2E-D** = the browser suites gameplay / features / story / drive.
- **PKG** = the packaged-build smoke test (Linux locally; Windows `Riverbound.exe` on GitHub Actions `windows-latest`).

## World

| Feature | Status | Evidence |
|-|-|-|
| Effectively infinite procedural river world | ✅ | U: 50 km downstream generates; E2E-D cruises with streaming, origin shifts and bounded geometry |
| Deterministic seeds; NEW WORLD → World seed | ✅ | U: same seed gives an identical world, a different seed a different one, and generation order doesn't matter; the Free Exploration seed field is exercised by E2E-F |
| 12 distinct biomes + a hidden one, gradual transitions | ✅ | U: 12 public biomes, adjacency graph respected over 10 seeds, ≥ 11 biomes reached; blending in `biomeAt` |
| Common, rare and unique landmarks | ✅ | 39 types; unique wonders once per world (`isUniqueRegion`); U: data references validated |
| Story locations placed in the right regions, persistent and reproducible | ✅ | U: all anchors land in range, in order, in fitting biomes, for 10 seeds; E2E-S reaches each one |
| Procedural events | ✅ | 14 events (`EventDirector`); E2E-F triggers events through the console |
| World memory (lamps, collected nodes, discoveries, villages) | ✅ | Saved in the session state; E2E-G and E2E-S save and load round trips |
| Rare discoveries (Starwater, unique wonders, legendary fish) | ✅ | The hidden river opens at night to the Lamplighter's lantern (E2E-S `veil` step) |
| Coherence over randomness | ✅ | U: water in the channel, no trees in deep water, adjacency rules, coast late |
